# Live Code Studio

A coding practice app: sign in, pick a problem, and grade your Python
solutions server-side (Run against visible tests, Submit against visible +
hidden tests). See [docs/specs.md](../docs/specs.md) for the full technical
spec.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://session-code-play.lovable.app

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
